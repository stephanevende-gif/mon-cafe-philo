# Guide pas à pas : mettre la nouvelle charte sur la chaîne YouTube

Durée : 20 minutes environ. Il faut un ordinateur, connecté au compte Google de la chaîne.
Tous les fichiers cités sont dans le dossier `kit-youtube` de l'archive.

## Avant de commencer : ce que contient le kit

| Fichier | À quoi il sert |
|---|---|
| `banniere.jpg` | La grande image en haut de la chaîne (2560 × 1440) |
| `profil.png` | La photo ronde de la chaîne (800 × 800) |
| `filigrane.png` | Le petit rond « M » qui s'affiche dans le coin des vidéos et permet de s'abonner |
| `atelier-miniatures.html` | Un petit outil pour fabriquer les miniatures des vidéos (voir étape 4) |
| `miniature-conference-exemple.png`, `short-exemple.png` | Deux exemples de miniatures |
| `textes-chaine.md` | Les textes à copier-coller (description, liens, titres) |

## Étape 1 : ouvrir YouTube Studio

1. Allez sur **studio.youtube.com** et connectez-vous.
2. Dans le menu de gauche, cliquez sur **Personnalisation**.
3. En haut, cliquez sur l'onglet **Branding** (ou **Image de marque**, selon la version).

## Étape 2 : changer les images

**La photo de profil**
1. Dans la case « Photo », cliquez sur **Modifier** (ou **Changer**).
2. Choisissez `profil.png`, puis cliquez sur **OK**.
YouTube découpe l'image en rond : le « M » reste bien au centre.

**La bannière**
1. Dans la case « Image de bannière », cliquez sur **Modifier**.
2. Choisissez `banniere.jpg`.
3. YouTube montre trois aperçus (téléviseur, ordinateur, téléphone). Ne touchez pas au cadrage : tout le texte est déjà placé dans la zone visible sur téléphone. Cliquez sur **OK**.
Sur ordinateur, les quatre couvertures de livres apparaissent de chaque côté ; sur téléphone, seul le texte central s'affiche, c'est voulu.

**Le filigrane**
1. Dans la case « Filigrane de la vidéo », cliquez sur **Importer**.
2. Choisissez `filigrane.png`, puis **OK**.
3. Pour « Durée d'affichage », choisissez **Fin de la vidéo** : le rond n'apparaît qu'à la fin et ne gêne pas pendant la conférence.

Cliquez enfin sur **Publier** en haut à droite.

## Étape 3 : changer les textes

1. Toujours dans **Personnalisation**, cliquez sur l'onglet **Informations générales** (ou **Infos de base**).
2. **Description** : effacez l'ancien texte et collez celui de la partie 1 de `textes-chaine.md`.
3. **Liens** : cliquez sur **Ajouter un lien** et recopiez les liens de la partie 2.
4. Cliquez sur **Publier**.
5. Les mots-clés (partie 3) se mettent dans **Paramètres** (roue dentée en bas à gauche) > **Chaîne** > **Informations générales** > **Mots clés**. Cliquez sur **Enregistrer**.

## Étape 4 : fabriquer une miniature pour une vidéo

1. Double-cliquez sur `atelier-miniatures.html` : il s'ouvre dans votre navigateur, sans internet.
2. Choisissez le format : **Conférence** ou **Short**.
3. Tapez la question et le nom de l'intervenant. Si vous avez un portrait de l'intervenant, ajoutez-le avec **Photo** et réglez le cadrage avec le curseur. Sans photo, un grand point d'interrogation le remplace.
4. Cliquez sur **Télécharger l'image** : le fichier arrive dans votre dossier Téléchargements.

**Poser la miniature d'une conférence**
1. Dans YouTube Studio, menu de gauche **Contenu**, cliquez sur le crayon de la vidéo.
2. Sous « Miniature », cliquez sur **Importer une miniature** et choisissez l'image. Cliquez sur **Enregistrer**.
(Si le bouton est grisé, YouTube demande de valider la chaîne par SMS une seule fois : suivez le message affiché.)

**Poser la couverture d'un Short**
Sur ordinateur, YouTube ne permet pas toujours de changer l'image d'un Short. Le plus simple : dans l'application YouTube sur le téléphone, au moment de publier le Short, touchez le petit crayon sur l'image, puis choisissez une image de la vidéo ou, si l'option est proposée, importez l'image fabriquée avec l'atelier.

## Étape 5 : vérifier

Ouvrez **youtube.com/@EditionsM-Editer** sur l'ordinateur puis sur le téléphone. La bannière, le rond « M » et la description doivent apparaître. Les changements peuvent mettre quelques minutes à s'afficher partout.
