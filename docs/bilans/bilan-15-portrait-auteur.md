# Bilan n°15 : portrait de l'auteur (27 octobre 2026)

## Ce qui a été fait
- Chaque nouvel auteur reçoit un **portrait provisoire** : l'image de sa vidéo longue sur la chaîne M-Éditer (ou de son Short s'il n'y a pas de vidéo longue). Ces images appartiennent à la chaîne, il n'y a donc pas de question de droits sur une photo trouvée ailleurs.
- Les 3 auteurs des fiches d'essai (André Stanguennec, Jean-Luc Nativelle, David Christoffel) ont reçu ce portrait.
- Tous les tests passent (28 sur 28). Code poussé sur la branche `claude/project-thread-1vzhmn`.

## Limites
- Depuis mon environnement de travail, les sites d'images (YouTube, recherche web) sont bloqués : je n'ai pas pu voir ces images, ni chercher une photo récente de l'auteur en ligne. Il faudra vérifier à l'écran que chaque image montre bien l'auteur.
- Pour remplacer un portrait : Administration › Intervenants › « Portrait (lien https) ». Pour l'instant, l'application n'affiche que les images venant d'elle-même ou de YouTube (règle de sécurité du site). Pour utiliser des photos d'un autre site, il faudra ouvrir ce site dans les réglages de sécurité, ou déposer les photos dans l'application.
